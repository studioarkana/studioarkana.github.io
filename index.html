☁ CONFIGURAR FIREBASE — SINCRONIZAÇÃO ENTRE DISPOSITIVOS

Por que configurar o Firebase?
Sem o Firebase, mudanças feitas no PC não aparecem no celular (elas ficam salvas só no navegador local).
Com o Firebase, tudo sincroniza em tempo real em qualquer dispositivo. É gratuito.

Como criar (5 minutos):
1. Acesse console.firebase.google.com e faça login com Gmail
2. Clique em Criar projeto → nome: studio-arcana
3. Vá em Compilação → Realtime Database → Criar banco de dados
4. Escolha Começar no modo de teste (mudar regras depois)
5. Vá em Configurações do projeto ⚙ → Seus apps → Adicionar app Web
6. Copie o objeto firebaseConfig e cole nos campos abaixo

Após conectar, todas as alterações feitas no painel admin são salvas na nuvem e aparecem em qualquer dispositivo automaticamente. As imagens ficam armazenadas como base64 no banco.
